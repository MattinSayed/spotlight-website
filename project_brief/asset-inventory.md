# SPOTLIGHT Dance Film Festival — Asset Inventory

## General Asset Guidance

The project contains a collection of visual assets for the SPOTLIGHT Dance Film Festival website.

These assets may include:

* Event photos
* Audience photos
* Cinema photos
* Group photos
* Behind-the-scenes photos
* Film stills
* Film posters
* Team photos
* Social media screenshots
* Video stills
* Poster mockups
* Other visual material related to the festival

Not every asset is individually documented yet.

When building the website, inspect the available images and use the strongest, most professional, and most relevant visuals throughout the page.

---

# Priority Rule

Some assets have descriptive filenames.

Assets with descriptive filenames should be treated as preferred assets and should be considered first.

For example, files with names such as:

* `hero`
* `audience`
* `cinema`
* `stage`
* `group`
* `team`
* `poster`
* `film-still`
* `bts`
* `behind-the-scenes`
* `recap`
* `interview`
* `vision-2027`
* `coming-2027`
* `frankfurt`
* `partner`
* `social-media`

should be prioritized for the matching website sections.

If a descriptive filename clearly indicates a suitable use, follow that indication.

Example:

* A file named `hero-cinema-audience.jpg` should be considered for the homepage hero.
* A file named `team-photo.jpg` should be considered for the Team & Contact section.
* A file named `film-still-01.jpg` should be considered for the About or 2026 Edition section.
* A file named `stage-group-photo.jpg` should be considered for the 2026 Edition section.
* A file named `poster-collage.jpg` should be considered for the 2026 Edition or visual gallery.
* A file named `vision-2027-poster.jpg` should be considered for the Vision 2027 section.

---

# Use Non-Descriptive Assets Too

There may also be many assets with generic or camera-generated filenames, such as:

* `IMG_1234.jpg`
* `DSC_0042.jpg`
* `photo-01.jpg`
* `image.png`
* `WhatsApp Image...jpg`

These should not be ignored.

After prioritizing descriptively named assets, inspect the remaining assets and use any that fit the website well.

Use non-descriptive assets if they are visually strong, professional, relevant, or better suited than the descriptively named files.

The final visual selection should be based on image quality, relevance, composition, and professional appearance — not only on filename.

# Image Quality Rules

Use images that are:

* Sharp
* High enough resolution
* Well-composed
* Relevant to the section
* Professional or artistically strong
* Suitable for a public-facing festival website
* Legally safe to publish

Avoid images that are:

* Blurry
* Very low-resolution
* Poorly lit without artistic value
* Random or unrelated
* Too casual for a professional partner-facing website
* Visually cluttered
* Unflattering to people shown
* Potentially not cleared for public use

---

# Cropping and Treatment

Images may be cropped for layout, but they should not be distorted.

Use cinematic aspect ratios when possible:

* Hero: wide cinematic crop
* Gallery: consistent grid crops
* Film stills: preserve cinematic framing where possible
* Team photos: natural, respectful crop

Use dark overlays where helpful for text readability.

Use subtle borders, shadows, or rounded corners only if they match the overall cinematic design.

---

# Rights and Safety

Before public launch, manually confirm that all published images are cleared for website use.

Pay special attention to:

* Film stills
* Film posters
* Photos of people
* Behind-the-scenes photos
* Social media screenshots
* Video stills
* Any copyrighted material

If rights are unclear, do not use the asset publicly.

For internal previews, unclear assets may be used temporarily, but they should be replaced or cleared before launch.

---

# Fallback Rule

If no suitable image is available for a section, create a clean visual placeholder instead of forcing a weak image.

Acceptable placeholders:

* Dark cinematic gradient
* Typographic “SPOTLIGHT” graphic
* “Coming Spring 2027” graphic
* Abstract spotlight shape
* Subtle film-frame style layout

The website should never look broken because an image is missing.

---

# Final Selection Rule

The final asset selection should prioritize:

1. Descriptive filenames that clearly match a section
2. Visual quality
3. Relevance to the section
4. Professional appearance
5. Cinematic/artistic feeling
6. Legal safety
7. Mobile and desktop usability

Use the best available assets, even if that means using a non-descriptive filename over a weaker descriptive one.
