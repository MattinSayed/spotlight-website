# SPOTLIGHT Dance Film Festival — Design Notes

## Overall Design Goal

The website should feel like a professional independent film festival website, not a generic event landing page.

It should communicate:

* Cinema
* Movement
* Dance
* International artistic exchange
* Frankfurt cultural scene
* Community
* Professional growth potential
* Credibility for partners and sponsors

The design should be visually strong enough to impress cinemas, sponsors, cultural institutions, press, and artists, while still feeling independent, human, and community-driven.

---

# Color Direction

## Preferred Palette

Use a dark cinematic base with warm highlight accents.

Suggested colors:

* Background: near-black / charcoal
* Secondary background: deep graphite / dark warm grey
* Text: off-white / soft white
* Secondary text: muted grey / warm grey
* Accent: warm spotlight gold / amber / soft champagne
* Optional secondary accent: deep red, muted copper, or warm beige

Suggested approximate values:

* Main background: `#080808` or `#0B0B0B`
* Section background: `#111111` or `#151515`
* Card background: `#1A1A1A`
* Main text: `#F5F1E8`
* Muted text: `#B8B0A3`
* Accent gold: `#D8A84E`
* Soft accent: `#F0D28A`
* Border: `rgba(255,255,255,0.12)`

Avoid:

* Bright primary colors
* Neon rainbow gradients
* Pure white backgrounds as the main design
* Generic blue corporate buttons
* Too many accent colors

## Color Usage

The site should mostly be dark and restrained.

Use the warm spotlight accent for:

* Buttons
* Small section labels
* Hover states
* Important numbers
* Dividers
* Subtle highlights
* Decorative lines

Do not overuse the accent color. It should feel intentional and premium.

# Typography

## Typography Direction

The typography should feel editorial and cinematic.

Use:

* Large strong headings
* Clean readable body text
* Generous line height
* Uppercase micro-labels for section tags
* Strong numeric treatment for statistics

Suggested font pairing:

Option A:

* Headings: elegant serif or high-contrast display font
* Body: clean sans-serif

Option B:

* Headings: bold modern sans-serif
* Body: clean sans-serif

Option C:

* All sans-serif, but use strong hierarchy and spacing

Good free Google Font directions:

* Headings: Playfair Display, Cormorant Garamond, Fraunces, DM Serif Display, or Space Grotesk
* Body: Inter, Manrope, Source Sans 3, or Work Sans

Preferred safe combination:

* Headings: Playfair Display or Space Grotesk
* Body: Inter or Manrope

If using a serif heading font, make sure it does not feel too wedding-like or luxury-brand-only. It should still feel contemporary and cultural.

## Type Hierarchy

Hero title:

* Very large
* Strong line breaks
* Should dominate first screen
* Must work on mobile

Section headers:

* Large, clear, elegant
* Use enough spacing before each section

Body text:

* Not too wide
* Max width around 680–760px for readability
* Comfortable line height

Statistics:

* Large numbers
* Small labels
* Strong contrast
* Could be displayed in cards or horizontal grid

# Layout Direction

## Structure

Use a one-page scrolling layout with sticky navigation and anchor links.

Sections:

1. Home
2. About
3. 2026 Edition
4. Vision 2027
5. Partners
6. Contact

The menu should be visible but not visually heavy.

## Page Rhythm

The page should alternate between:

* Large cinematic hero
* Text-led editorial sections
* Image grids
* Statistic cards
* Partner information cards
* CTA sections

Avoid making every section look the same.

## Layout Principles

Use:

* Generous spacing
* Strong visual hierarchy
* Large images
* Dark cards
* Thin borders
* Subtle dividers
* Controlled contrast
* Balanced whitespace
* Asymmetric but clean layouts if possible

Avoid:

* Cramped text
* Too many boxes
* Too many icons
* Overly symmetrical template feel
* Cluttered galleries
* Generic stock-photo layouts

# Hero Section

## Goal

The hero should create immediate impact.

It should answer within five seconds:

* What is this?
* Where is it?
* Why does it look credible?
* What happened already?
* What happens next?

## Hero Content

Use:

* SPOTLIGHT Dance Film Festival
* Short subtitle
* One-sentence explanation
* Key facts
* CTA buttons

## Hero Visual

Use the strongest available image or video still.

Ideal hero image:

* Cinema atmosphere
* Audience watching
* Stage/group moment
* Strong dance film still
* Dark image with space for text overlay

Hero treatment:

* Full-width or split-screen
* Dark overlay if text is on image
* Warm spotlight gradient
* Subtle grain/noise texture if tasteful
* Large title
* Key facts visible near the fold

Avoid:

* Low-resolution image
* Busy image behind small text
* Bright daylight photo as main hero unless very strong
* Random collage as the first visual unless designed carefully

# Section-Specific Design Notes

## 1. Home

Use a cinematic hero with strong title and event proof.

Possible layout:

* Left: title, intro text, buttons
* Right: large image
* Below: key stats strip

Alternative:

* Full-screen background image
* Dark overlay
* Centered title and text
* Stats below

Must feel impressive.

## 2. About

Make this section more editorial.

Possible layout:

* Section label: About
* Large heading
* Body text in readable width
* Side image or image pair
* Pull quote

Possible pull quote:

“Dance film deserves to be experienced collectively — on the big screen, with full attention.”

## 3. 2026 Edition

Make this section proof-heavy.

Use:

* Statistic cards
* Event photos
* Poster/film still grid
* Clear text about success
* Sold-out highlight

The “Sold out” fact should be visually prominent.

Possible visual treatment:

* Large “2026” background number
* Photo grid
* Stats row
* Quote placeholder only if real quote exists

## 4. Vision 2027

Make this section forward-looking and ambitious.

Use:

* “Coming Spring 2027” visual
* Timeline or planned format cards
* Warm accent color
* Larger CTA toward partners

Should feel like a project growing professionally, not like vague dreaming.

## 5. Partners / Cinemas

This section should be especially clear and credible.

Use:

* Professional card layout
* Partner value points
* “What SPOTLIGHT brings” checklist
* Audience description
* Cooperation models
* Conservative reach statement

Avoid making it too text-heavy. Use cards and columns.

This section should feel like it could be shown to a cinema manager, sponsor, or funding body.

## 6. Team & Contact

This section should feel human and warm.

Use:

* Team photo if available
* Names in clean cards or a simple list
* Contact email button
* Instagram link
* Frankfurt location

Do not overdesign this section.

# Imagery Direction

## Image Style

Prioritize images that feel:

* Cinematic
* Real
* Emotional
* Atmospheric
* Professional
* Community-oriented
* Movement-based

Good image types:

* Audience in cinema
* Projection / screen / stage
* Dancers in motion
* Film stills with strong composition
* Behind-the-scenes moments
* Team working
* Group photo after screening
* Poster collage

Avoid:

* Blurry low-quality images
* Images with poor lighting unless artistically strong
* Random screenshots with messy UI
* Overcrowded collages
* Images that look too casual for partner-facing pages
* Any image where usage rights are unclear

## Image Treatment

Use:

* Cropping for cinematic aspect ratios
* Subtle dark overlays
* Rounded corners only if tasteful
* Thin borders
* Lazy loading
* Descriptive alt text
* Responsive sizes

Suggested aspect ratios:

* Hero: 16:9 or wide cinematic
* Cards: 4:3 or 3:2
* Film stills: preserve original cinematic ratio if possible
* Team photo: natural crop

Do not distort images.

## Video

If using video:

* Prefer embedded Vimeo/YouTube if available
* Or use a short compressed MP4/WebM
* Do not autoplay with sound
* If autoplaying muted background video, ensure performance is acceptable
* Always provide a fallback image

# Responsive Design Requirements

The site must look polished on:

* Mobile phones
* Tablets
* Laptops
* Large desktop screens

Mobile is very important.

Mobile requirements:

* Hero title must not overflow
* Images must scale correctly
* Navigation must be usable
* Cards should stack cleanly
* Text should remain readable
* Buttons should be easy to tap
* Large sections should not feel overwhelming
* No horizontal scrolling

Desktop requirements:

* Use available space elegantly
* Avoid overly wide text columns
* Use image/text split layouts
* Keep sections visually rich

---

# Accessibility Requirements

Use:

* Semantic HTML
* Proper heading hierarchy
* Descriptive alt text
* Keyboard-accessible navigation
* Sufficient contrast
* Focus states for links and buttons
* Accessible button text
* Reduced motion support if animations are used

Avoid:

* Text embedded only inside images
* Low contrast grey text
* Hover-only interactions
* Excessive motion
* Tiny text
* Unlabeled links

---

# Motion / Animation

Use only subtle animation.

Good:

* Gentle fade-in
* Slight image reveal
* Button hover transitions
* Subtle parallax only if performance remains good
* Smooth anchor scrolling

Avoid:

* Flashy animations
* Overly complex scroll effects
* Distracting motion
* Anything that hurts mobile performance

Motion should support the cinematic feeling, not dominate the site.

# Performance Requirements

The site should be lightweight and fast.

Use:

* Optimized images
* Lazy loading for non-hero images
* Minimal JavaScript
* Static rendering
* Compressed assets
* No unnecessary libraries

Avoid:

* Huge uncompressed images
* Large video files in the repository
* Heavy animation libraries
* Unused CSS frameworks
* Client-side rendering for static content

If using Astro, prefer static output.

---

# Collaboration / Maintainability

The project should be easy for Mattin and the team to maintain.

Recommendations:

* Keep content organized clearly
* Use readable component names
* Use a clean folder structure
* Put repeated data such as stats/team/contact in structured arrays if helpful
* Add comments only where useful
* Write a README with simple instructions

README should include:

* Project overview
* How to install dependencies
* How to run locally
* How to build
* How to deploy to Netlify
* Where to edit content
* Where to add images
* Contact for project owner

# German Legal Note

Because SPOTLIGHT is based in Germany, a public website may need an Impressum and privacy policy depending on how it is used.

For the first internal preview, this is not urgent.

Before broad public launch, add:

* Impressum
* Privacy policy / Datenschutz
* Responsible person/entity
* Contact details
* Any required legal information

Do not invent legal text. Use confirmed information.
