# SPOTLIGHT Dance Film Festival — Website References & Inspiration

## Purpose of This File

This file gives visual and structural inspiration for the SPOTLIGHT Dance Film Festival website.

Do not copy any referenced website directly. Use these references only as conceptual inspiration for layout, mood, hierarchy, typography, navigation, editorial structure, and partner-facing credibility.

The goal is to build an original website for SPOTLIGHT that feels:

* Cinematic
* Professional
* Artistic
* Independent
* Community-oriented
* Credible to cinemas, sponsors, press, artists, and cultural partners

---

# Core Reference Direction

SPOTLIGHT should combine three worlds:

1. Independent film festival credibility
2. Contemporary dance / movement-based artistic identity
3. Clean partner-facing cultural project presentation

The website should not feel like a generic event page. It should feel like a serious cultural platform that already had a successful first edition and is preparing to grow.

---

# Reference 1 — Dance on Camera Festival

Reference URL:

https://www.dancefilms.org/festival

## Why This Reference Matters

Dance on Camera is directly relevant because it is a dance film festival. Its positioning is useful for understanding how dance film can be framed as a serious artistic and cinematic field.

Important ideas to study:

* How it explains dance film as a form of choreographic storytelling
* How it frames the festival as a platform for filmmakers, choreographers, dancers, and audiences
* How it connects screenings, workshops, panels, special programs, and community
* How it positions the festival as both artistic and professional

## What To Borrow Conceptually

Borrow the seriousness of the positioning.

SPOTLIGHT should also clearly communicate:

* Dance film is a real cinematic art form
* The festival serves artists and audiences
* The festival creates community around screenings
* The festival is not only an event, but a platform

## What Not To Copy

Do not copy layout, wording, branding, structure, or visual identity.

SPOTLIGHT should look more cinematic, darker, and more visually atmospheric.

# Reference 2 — Short Shorts Film Festival & Asia

Reference URL:

https://www.shortshorts.org/en/

## Why This Reference Matters

Short Shorts Film Festival & Asia is useful as a reference for how a short film festival presents itself as more than a screening event. It positions itself as a broader short film brand involving screenings, distribution, production, and collaborations.

Important ideas to study:

* How the festival explains its history and credibility
* How it frames itself as a platform for future filmmakers
* How it communicates international reach and cultural importance
* How it separates festival identity, programming, collaborations, and institutional credibility

## What To Borrow Conceptually

Borrow the sense that a festival can become a larger cultural platform.

For SPOTLIGHT, this supports the idea that:

* The first edition was proof of concept
* The 2027 edition is a step toward a recurring platform
* Partners are not just supporting one event, but helping build a cultural format
* The website should communicate long-term potential

## What Not To Copy

Do not copy its dense information structure.

SPOTLIGHT should be much more minimal, visual, and cinematic because it is still early-stage and partner-facing.

# Design Patterns To Implement

## 1. Cinematic Hero

Implement a strong opening section with:

* Large SPOTLIGHT title
* Short explanation
* One strong hero image or video still
* Dark overlay or split layout
* Key stats visible near the top
* CTA buttons

The hero should immediately communicate:

* This is a dance film festival
* It is based in Frankfurt
* The first edition sold out
* The next edition is planned for spring 2027

## 2. Editorial About Section

Implement an elegant text-led section with:

* Large section heading
* Readable text width
* Pull quote
* Supporting visual
* Optional small cards explaining dance / film / community

This section should feel thoughtful and artistic.

## 3. Proof-of-Concept 2026 Section

Implement a credibility-focused section with:

* Strong event photo
* Clear recap text
* Statistic cards
* Image grid
* “Sold out” highlighted visually

This section should make visitors believe the project already worked.

## 4. Vision 2027 Section

Implement a forward-looking section with:

* “Coming Spring 2027” visual treatment
* Planned format cards
* Timeline or structured list
* CTA toward partners
* Ambitious but realistic tone

This section should feel like growth, not vague dreaming.

## 5. Partner-Facing Section

Implement a clear professional section with:

* What SPOTLIGHT brings
* Partner value
* Audience description
* Cooperation models
* Conservative reach statement
* Contact CTA

This section should be easy for a cinema manager, sponsor, cultural institution, or funding person to scan quickly.

## 6. Human Team / Contact Section

Implement a warm final section with:

* Team names
* Team photo if available
* Email
* Instagram placeholder
* Frankfurt location
* Mailto button

This section should feel real and approachable.

# Layout Patterns To Use

## Recommended Layout Mix

Use a mix of:

* Full-width hero
* Two-column image/text sections
* Stats strip
* Editorial text blocks
* Image grid
* Feature cards
* CTA panels
* Simple team/contact area

Avoid using the same card grid for every section.

## Section Rhythm

Suggested flow:

1. Big cinematic impact
2. Calm explanation
3. Strong proof
4. Future vision
5. Professional partner pitch
6. Human contact

This rhythm should guide the page.

# Visual Implementation Notes

## Color

Use a dark cinematic palette with warm spotlight accent.

Suggested:

* Near-black background
* Charcoal cards
* Off-white text
* Muted grey secondary text
* Gold/amber highlight

## Typography

Use strong cinematic/editorial typography.

Suggested:

* Large display heading for SPOTLIGHT
* Clean sans-serif body text
* Strong numeric treatment for stats
* Small uppercase labels

## Imagery

Use real SPOTLIGHT photos and stills wherever possible.

Prioritize:

* Descriptive filenames
* Hero/cinema/audience images
* Group/stage photos
* Film stills
* Poster images
* Team photos

If assets are missing, use tasteful placeholders.

## Motion

Use subtle motion only:

* Gentle fade-ins
* Hover states
* Smooth anchor scrolling

Avoid flashy scroll effects.
